# Portfolio

General engineering guidelines and the development flow live in `~/.claude/CLAUDE.md`.
This file holds only what is specific to this project.

## Stack
- Next.js + React + TypeScript
- Tailwind CSS (PostCSS/Autoprefixer), Framer Motion
- Hygraph (GraphCMS) as content source, with PT-BR / EN locales
- react-hook-form for forms
- Jest + Testing Library for tests

## Commands
- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run lint` — lint
- `npm test` — run Jest tests
